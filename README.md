# Evidentiary Governance for LLM Agents: Replication Materials

This repository is the planned replication artifact for *Evidentiary Governance for LLM Agents: Runtime Control and Proposal-Level Evaluation* by Hiroshi G. Okuno and Mayumi J. Okuno.

**Status:** The replication materials are being prepared and are not yet available in this repository. We plan to release a versioned package following peer review. This README will be updated with its contents and reproduction instructions when the package is released.

## Planned contents

The package is intended to include:

* The governance runtime, encoded norms, configurations, and scripts needed to reproduce the E1 and E2 runtime analyses.
* Scenario definitions, proposal inputs, and case-level results for the fixed-proposal and model-generated experiments.
* The original and revised LLM annotation instructions, blinded cases, recorded case-level judgments, and validation and analysis scripts.
* The clarified norm representations and 12 selected cases, together with the blind-ID mapping used by the researchers after annotation.
* Scripts and instructions for recalculating the paper’s tables and case-level comparisons.

## Scope of reproduction

The recorded inputs and judgments will permit independent recalculation of the reported results. Re-running the runtime experiments will require the software and configurations provided with the release. Re-querying hosted LLM services may produce different judgments because those services can change over time; recalculation from the archived judgments does not depend on re-querying them.

The release will identify the software revision, dependencies, and commands used for reproduction.

## Citation

Please cite the paper when using these materials. A complete citation and a link to the versioned release will be added when available.
